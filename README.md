# Game Dev Portfolio

Angular portfolio site for Michel van der Linden.

## Available Scripts

Run these commands from the project directory:

### `npm start`

Starts the Angular development server. Open the URL printed in the terminal.

### `npm test`

Runs the Angular unit tests once with Vitest.

### `npm run build`

Builds the production site into the `build` folder.

### `npm run deploy`

Builds the site and publishes the `build` folder to GitHub Pages.
